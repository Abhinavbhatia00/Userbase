# Userbase

A user management application created by **Abhinav Bhatia** for the **SynergyLabs Frontend Internship Assignment**.

I built this project to demonstrate my understanding of React components, hooks, API integration, form handling, CRUD operations, responsive design, and loading and error states.

## Live Website

[Userbase Live](https://userbasesynlabs.vercel.app/)


## Features

- View users in a responsive table
- View a separate details page for each user
- Add and edit users with form validation
- Delete users after confirmation
- Loading, success, and error feedback

## Tech used

- React
- Vite
- Axios
- React Router
- Tailwind CSS

## API note

JSONPlaceholder simulates POST, PUT, and DELETE requests but does not save them permanently. The app stores the updated list in local storage so changes remain visible while testing the project.
